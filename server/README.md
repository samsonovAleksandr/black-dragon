# Сервер «Чёрного Дракона»

Раздаёт игру (`../index.html`, `../vendor/*.js`) и пересылает сообщения между хостом и гостями по WebSocket (`/ws`).
Игровая логика остаётся в браузере хоста, поэтому сервер лёгкий (хватит любого мини-ПК или Raspberry Pi).

## Запуск

```bash
npm install
npm start            # порт 8080; другой порт: PORT=3000 npm start
```

Проверка: <http://localhost:8080/health> → `ok rooms=0`.
Игроки открывают `http://АДРЕС:8080/`; хост жмёт «Создать комнату», друзья — «Войти по коду».

## Протокол (кратко)

| Сообщение | Кто шлёт | Действие |
|---|---|---|
| `{op:'host', code?}` | хост | создать комнату (можно запросить прежний код при возвращении) |
| `{op:'join', code}` | гость | войти в комнату |
| `{op:'to', id, m}` | хост | отправить сообщение гостю |
| `{op:'toHost', m}` | гость | отправить сообщение хосту |

Сервер выдаёт гостям уникальные id, закрывает комнату при уходе хоста и держит соединения живыми (ping каждые 25 с).
