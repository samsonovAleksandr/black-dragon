# Сервер «Чёрного Дракона»

Раздаёт игру (`../index.html`, `../js/*.js`, `../vendor/*.js`) и пересылает сообщения между хостом и гостями по WebSocket (`/ws`).
Игровая логика остаётся в браузере хоста, поэтому сервер лёгкий (хватит любого мини-ПК или Raspberry Pi).

## Запуск

```bash
npm install
npm start            # порт 8080; другой порт: PORT=3000 npm start
```

Проверка: <http://localhost:8080/health> → `ok rooms=0`.
Игроки открывают `http://АДРЕС:8080/`; хост жмёт «Создать комнату», друзья — «Войти по коду».

## Протокол (кратко)

| Сообщение | Кто шлёт | Действие |
|---|---|---|
| `{op:'host', code?}` | хост | создать комнату (можно запросить прежний код при возвращении) |
| `{op:'join', code}` | гость | войти в комнату |
| `{op:'to', id, m}` | хост | отправить сообщение гостю |
| `{op:'toHost', m}` | гость | отправить сообщение хосту |

Сервер выдаёт гостям уникальные id, закрывает комнату при уходе хоста и держит соединения живыми (ping каждые 25 с).

Готовые конфиги systemd и nginx лежат в папке [`../deploy`](../deploy).

## Лимиты (защита от злоупотреблений)
Все значения можно переопределить переменными окружения:

| Что | По умолчанию | Переменная |
|---|---|---|
| Комнат на сервере | 200 | `MAX_ROOMS` |
| Открытых комнат с одного адреса | 4 | `MAX_ROOMS_PER_IP` |
| Соединений с одного адреса | 30 | `MAX_CONN_PER_IP` |
| Создание комнат в минуту с адреса | 10 | `MAX_CREATE_PER_MIN` |
| Неудачных входов по коду в минуту (перебор кодов) | 15 | `MAX_BADJOIN_PER_MIN` |
| Сообщений на соединение: всплеск / в секунду | 300 / 120 | `MSG_BURST` / `MSG_PER_SEC` |

За nginx реальный адрес берётся из `X-Real-IP` / `X-Forwarded-For` (только если запрос пришёл с этой же машины).
